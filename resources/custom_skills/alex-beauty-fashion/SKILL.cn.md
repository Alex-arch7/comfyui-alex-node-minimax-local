# Alex 美女时尚写真生成器（alex-beauty-fashion）中文版说明

> 本文件供人阅读；节点实际注入的是 SKILL.md（英文）+ references/ 全部文件。

把成年女性的参考照片 + 一句话创意，变成可直接渲染的 MiniMax H3 竖屏短片提示词（9:16，4–15秒）。
全部规则提炼自 49 条精选参考视频语料（4.7–11.4 秒，均值 8.3 秒，24fps，96% 带原生音频）。

## 适用 / 不适用

- 适用：单人成年女性主体、时尚氛围短片、写真动态化、可爱或魅惑动作展示、国风旗袍/汉服。
- 不适用：多人剧情、产品广告（用 minimalist-product-ad-generator）、动画、恐怖、露骨内容、
  真人明星脸、复刻水印。

## 七步流程

1. **素材与身份锁**：至少一张参考图；锁脸、发型、妆容、服装、饰品、身材比例，跨镜头不漂移。
   2–3 张图（脸部特写+全身服装+场景）走 Ref2VA 标 `<Picture 1..3>`；单张首帧走 I2VA。
   年龄必须清晰成年；模糊时把造型推向成熟时尚并在提示词写明 adult woman。
2. **选子类型**（语料八大类）：城市漫步lookbook / 夜街霓虹魅惑 / 可爱日常 / 国风旗袍汉服 /
   度假泳池 / 极简建筑 / Cosplay二次元 / 运动网纱。按关键词、服装、场景自动选，拿不准问一句。
3. **节拍语法**：4–7秒=一个节拍（入场或单一动作，定格收尾，别塞满）；8–11秒=三节拍
   （钩子0–2s → 发展2–7s → 收尾最后1.5–2s定格/回眸）。语料最高频收尾=回眸（身转开、脸回镜头、定格）。
4. **动作链**：每条视频用一条链；系列出片时固定参考图+子类型、轮换动作链（完整中英库见
   references/action-library.md）。
5. **运镜与布光**：固定机位+主体走位为主，每条最多一次缓推；景别三段式（全身→中景→特写）；
   自拍臂距适合可爱日常；低角度仰拍适合国风；可选离场节拍（走出画面带轻微动态模糊）。
   布光五配方：黄金时刻逆光/阴天柔光/夜街霓虹散景/暖灯室内/日落天空背景——光源必须写具体。
6. **声音**：拟音（脚步/布料/发丝/环境/一个道具声）+ 配乐（魅惑=稀疏低速鼓点、可爱=轻拨弦、
   国风=古筝笛混合），配乐压在环境声之下，不要呻吟式人声、不要屏幕歌词。
7. **写 H3 提示词**：按检测模式遵循 h3-prompt-writing 字段结构（紧凑契约见
   references/h3-field-contract.md）；时间戳 MM:SS.mmm 且不超时长；标签全篇一致；
   具体名词胜过抽象形容词；不编造屏幕文字/水印。

## 硬性禁止

仅成年主体；无裸露与性暗示；无窥视机位；不复刻明星脸与水印；无肢体畸形/多指；
不过度磨皮；无非自愿情境；服装饰品不得跨镜头瞬移。

## 输出自检

成年感清晰 / 脸部锁定参考 / 每拍一个姿态 / 时间线不超时长 / 标签一致 / 光源具体 /
至少两个拟音 / 收尾是定格或回眸 / 无编造文字水印 / 无违禁内容。
